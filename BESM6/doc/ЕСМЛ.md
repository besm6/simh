# ЕСМЛ: накопитель на МЛ ЕС-5017 на направлении 4

Анализ исходных текстов Диспака БЭСМ-6 (`~/git/re-dispak/*.be`) и реализация
в симуляторе. Ссылки вида `файл:строка` относятся к `re-dispak`, ссылки на
`besm6_*.c` — к симулятору. Разряды нумеруются с 1 справа.

## Итог

- **ЕСМЛ** — поддержка в Диспаке накопителя на магнитной ленте ЕС-5017
  (КУС ЕСМЛ), подключённого вместо родного контроллера на направление 4.
  Её включает раздел ВЫДИНСа `ЕСМЛ N`. Драйвер — модуль `esml.be` (СТАРТ
  `'62000'`, зона 0671). В родной драйвер МЛ он встроен через крючки в
  `khlam.be`.
- Работает только **N=4**: `esml.be` жёстко использует `увв '110'` и
  `уиа 4(М16)`. В стандартном `sbor2053.bin` `ЕСМЛ 4` стоит в вариантах
  1, 3, 4, 6, 7, 9, 10 и 11; демонстрационная загрузка (машина 3) идёт
  именно с ним.
- В симуляторе: `set mg4 es` превращает MG4 в ЕС-5017,
  `tools/makeBESM2053.py --es` / `--no-es` ставит или гасит `ЕСМЛ 4` в зоне
  конфигурации.
- Проверено на ОС:
  - чистая лента ставится директивой `ЕСМ` (ответ `МГ 40-1234 ЕС`);
  - ленту в режиме БЭСМ-6 ОС опознаёт сама (`1234 - 40`).
- Не сделано: переменная длина зоны (`033 0177/4177`) — см. TODO в конце.

## 1. Конфигурация

**Раздел ВЫДИНСа** `ЕСМЛ N` (`rukava.be:2879-2881`, раздел 2.2.47): «наличие
МЛ ЕС 5017, N — номер направления (3,4. стандартно 4-е напр)».
- `vydins.be:1063-1077` проверяет N и делает `ИЛИ N<<45` в `КОНФИГ+1`, т.е.
  в слово 1 варианта, разряды 46–48.
- РУКАВ (`rukava.be:3005-3007`): «46-48Р.: ЕСМЛ=ЗНАЧ. (корр. знач. 3 или 4;
  1,2,7 — недопуст., 5=3, 6 — ничего не изм.)».

**Загрузка.** Если разряды 46–48 не нули, ГЕНС1:
- грузит зону 0671 в `'62000'` (`gens1.be:940-944`, `gens.be:553`,
  `rukava.be:1891,2123`);
- ставит `ЕС5017 = МДС>>45`, т.е. номер направления (`gens1.be:976-978`).

**Почему только 4.** От N зависят сравнения во всех крючках, `М1 = 8N+u`
и номер разряда ГРП конца движения. Но `esml.be` во многих местах пишет
прямо `увв '110'` (`esml.be:71,95,841,860-867` и др.) и `уиа 4(М16)`
(`esml.be:52,81,119`). Крючок на ГРП есть только для направления 4
(`disp70.be:1330-1331`).

**Скрипт.** `tools/makeBESM2053.py --es` пишет 4 в разряды 46–48 слова 1
всех непустых вариантов (или заданных `--variant`), `--no-es` их гасит.
Служебные слова зоны, кроме контрольной суммы, не меняются.

## 2. Встраивание в ОС

`khlam.be:12-160` — крючки вида `счи М16; нтж ЕС5017; пе <родной путь>;
пб <путь ЕС>`. Через них проходят:
- позиционирование (`ПОДВ80` → `ЗД` или `'40'`);
- начало обмена (`Н1193` → `закес`);
- конец движения (`н1352` → `е1352`) и конец обмена (`Н1351` → `е1351`);
- анализ НЛ-КЛ (`н1348` → `е1348`) и чтение МГЗ (`н1469` → `е1469`);
- медленный таймер (`врмл` → `START`).

Обмен с ЛЕНТОЙ ЕС (признак `ТЗНМЛ` разр.13 «ЗАНЯТ ЕСМЛ», `rukava.be:1269`)
идёт целиком через `esml.be`. Лента в режиме БЭСМ-6 на приводе ЕС
обслуживается родным `dmlmb.be` с подменой команд движения.

## 3. Адреса

На направлении 4 ЕС-5017 занимает ресурсы родного контроллера и добавляет три
регистра:

| `увв` | Назначение | Где |
|-------|------------|-----|
| `0110+u` (= `050+М1`) | выбор МЛ u, команда движения | `esml.be:142,701,751,841,860-867`, `vzu.be:2071` |
| `5` | слово обмена (общее с направлением 3, канал 5) | `dmlmb.be:1331-1335` |
| `04115` | регистр состояния выбранного МЛ | `esml.be:28,74,145,703,1041,1557` |
| `04117` | регистр ошибок | `esml.be:1166,1201-1219,1362` |
| `04012` | число считанных слов | `esml.be:1240,1267` |
| `04035` разр.3 | ОШМ канала 5 | `esml.be:1192` |
| `031` (СМ=4) | имитация конца обмена (ГРП 27) | `esml.be:549-550` |
| `0177`/`04177` | переменная длина зоны | `esml.be:1153,1466-1473`, `gens1.be:976-987` |

Номер канала: `М2 = (dir+7)>>1` (`dmlmb.be:1801-1805`), т.е. 5 и для
направления 3, и для 4. Служебные слова лежат в `КНАПР-1(М2)` = `050`
(`disp70.be:226-231`). Ячейки `040`–`047` — канал 4, диски.

Прерывания:
- ГРП 27 (`GRP_CHAN5_FREE`) — конец обмена;
- ГРП 35 (`GRP_CHAN4_DONE`) — конец движения, гасится командой с разр.24.

## 4. Команда `увв '110'+u`

Запись нуля только выбирает МЛ, его состояние затем читается по `04115`
(`esml.be:139-145,1038-1043`). Разряды по блокноту Е.Н. Голенковой
(`rukava.be:1340-1355`):

| Разр. | Действие |
|-------|----------|
| 3 | зона вперёд (с обменом, заданным `увв 5`) |
| 4 | зона назад |
| 5 | группа зон вперёд (за МГЗ) |
| 6 | группа зон назад |
| 7 | запись маркера группы зон (МГЗ) |
| 8 | стирание промежутка, ~150 мм |
| 9 | перемотка в начало |
| 10 | перемотать и разгрузить |
| 11 / 12 | низкая (8 стр/мм) / высокая (32 стр/мм) плотность |
| 13 | программный останов, кроме операций по 9–10 |
| 24 | гашение окончания движения |

Разряд 1 ОС ставит при обменах ЕС, движениях по приказу и повторах
(`esml.be:530,639,804,1474-1477`). Его смысл неизвестен.

**Движения по приказу задачи** (`esml.be:249-287`). `РЯО1` (разр.40–42
`ИНФСЛЭ`) переходит в разряд `РЯО1+1`:
- 2 → зона вперёд, 3 → зона назад;
- 4 → группа вперёд, 5 → группа назад;
- 6 → перемотка, а при разр.27 — разгрузка;
- 7 → МГЗ, а при разр.27 — стирание.

**Лента БЭСМ-6 на приводе ЕС.** Позиционирование вперёд — `ЗД` (020,
группа вперёд), назад — `'40'` (группа назад) (`khlam.be:36-48`,
`esml.be:121`). Обмен — разряд 3.

## 5. Слово обмена `увв 5`

Для ленты ЕС его строит `МГНОР` (`esml.be:565-579`), отдаёт
`ЗКМЛ4П` (`dmlmb.be:1331-1335`):

```
слово = КУС & ~(Е11|Е26|Е25) | рзб(ЛИС2, П14037) | (КУС & Е26Е25)>>24 | Е4
```

Разряд 20 гасится.

| Разр. | Смысл |
|-------|-------|
| 1–2 | абзац ОЗУ (четверть листа) для короткой зоны (`esml.be:398-401`) |
| 4 | 1 — режим ЕС: 6 байтов на слово, без служебных слов; 0 — режим БЭСМ-6 |
| 8–10 | номер МЛ |
| 13–17, 24–30 | физический лист: `П14037` раскладывает 12 разрядов `ЛИС2` |
| 18 | чтение (`ИНФСЛЭ` разр.40, `esml.be:411-415`) |
| 19 | 1 — длинная зона, 2000 слов; 0 — короткая, 400 (`rukava.be:1338-1339`) |
| 21 | только служебные слова (родное слово БЭСМ-6) |
| 27 / 28 | плотность (`esml.be:402-410`, ровно один из двух) |
| 29 | переменная длина |
| 30 | разметка ЕС |

Плотность попадает в разряды 27–28, т.е. в старшие разряды номера листа.
Поэтому контроллеру остаются листы 0–255.

## 6. Регистр состояния `04115`

| Разр. | Смысл | Где |
|-------|-------|-----|
| 1 | лента движется | будильник `esml.be:74-97` |
| 5 | запись разрешена | `esml.be:591-595,990-997` |
| 6 | НЛ (начало ленты) | `esml.be:29,703-711,1303-1318` |
| 7 | КЛ (конец ленты) | `esml.be:1303-1318,1333-1335` |
| 8 | готовность | `esml.be:146-151,1426-1436` |
| 9 | идёт перемотка (вместе с 8) | `esml.be:146-151` |

Условия, которые проверяет ОС:
- у готового стоящего МЛ `(РС & 0600) == 0200` (`esml.be:1051-1055,1558-1561`);
- конец перемотки: разр.6 есть и `РС>>7 == 1` (`esml.be:28-34`).

## 7. Регистр ошибок `04117` и счётчик `04012`

| Разр. | Смысл |
|-------|-------|
| 11 | вместо зоны считан МГЗ — ответ 3 (`esml.be:1173-1177,1201-1207,1362-1365`) |
| 12 | длинная зона (> 1024 слов) — ответ 5 (`esml.be:1208-1209`) |
| 13 | ОШЦКС; при записи, если других ошибок нет, не учитывается (`esml.be:1211-1218`) |
| 9, 10, 13, 14 | маска `МСК` (`esml.be:1222-1227,1578`), код аварии `015` + номер разряда |

`04012`: после удачного чтения ОС кладёт `сч<<5` в М16 задачи
(`esml.be:1267-1277`). М16 15-разрядный, поэтому 2000 слов дают 0.

## 8. Последовательности

**Опрос готовности.** `ЧТРС` (`esml.be:133-170`) выбирает по очереди МЛ
`0110..0117` и читает `04115`. Маску готовых он отдаёт НОМБОБу. Это те самые
«группы по 8» обращений к `04115`, которые раньше видели в симуляторе.

**Обмен с лентой ЕС:**
1. `увв 031` с СМ=4 (`esml.be:549-550`).
2. Слово обмена, затем `увв 5`.
3. Команда `Е1|Е3|ПЛОТН` в `0110+u` (`esml.be:1474-1479`).
4. Будильник: `ДОП`=1, `ДОПВР`=128 тиков медленного таймера
   (`esml.be:1386-1398,1442`).
5. В конце `е1351` требует `(РС & 0600) == 0200`, затем разбирает `04117`
   и `04012` (`esml.be:1045-1277`).

**Будильник.** Медленный таймер (ГРП 10, в симуляторе ~62,5 Гц) считает
`ДОП` до `ДОПВР`. Затем:
- если РС разр.1 есть, ОС пишет `Е13`;
- если нет, ставит признак «БЕЗ ДВИЖЕНИЯ», и это ошибка (`esml.be:56-99`).

Окна: 0,5 с (МГЗ), 2 с (обмен), 4 с (движение), 131 с (перемотка).

**Перемотка** не занимает направление (`esml.be:1387-1392`). Её конец ОС
находит опросом по медленному таймеру: выбирает МЛ, проверяет НЛ и
`РС>>7 == 1`, пишет `Е13` и `Е24` (`esml.be:18-45`).

**Повторы.** До 8 раз зона назад (`Е1|Е4`) и повторное чтение
(`esml.be:1228-1266`).

## 9. Лента в режиме БЭСМ-6: МГЗ перед каждой зоной

ОС держит признак «СТОИМ ПЕРЕД МГЗ» (`МГЗ`, разряд `E8(М15)`):
- ставит его при постановке ленты (`мл2д`, `esml.be:1523-1525`) и после
  каждого движения (`устмгз`, `esml.be:1408-1422`);
- гасит после движения `Е4` или `Е5` (`КУСДВ & 030`);
- перед обменом при поднятом признаке пропускает МГЗ командой `Е5`
  (`закес`, `esml.be:1002-1012`).

Отсюда разметка: `НЛ МГЗ З0 МГЗ З1 МГЗ З2 …`. Это подтвердил трасс опознания
ленты при загрузке: группа вперёд → чтение служебных слов зоны 0 → группа
вперёд → чтение зоны 1 → `1234 - 40`.

## 10. Постановка ленты

- **Опознание.** НОМБОБ видит готовый МЛ и пытается прочитать метку как с
  ленты БЭСМ-6. На чистой ленте это не выходит, и он выдаёт `ПР.МГ - 40`
  (`nombob.be:36`).
- **Чистая лента** ставится директивой 7: `ЕСМ <N боб> <N у-ва>`
  (`cirkul.be:117-121`). Ответ — `МГ 40-1234 ЕС`; `мл2д` ставит ленте
  признак ЛЕНТЫ ЕС. Если у-во не на направлении ЕС, ответ — «НЕТ:ЕСМЛ»
  (`cirkul.be:185-188`).
- **Порядок оператора.** До директив работы ОС требует `СМЕ N`,
  `ДАТ ДД ММ`, `ВРЕ ЧЧ ММ`, иначе отвечает `К РАБ. НЕ ГТ`
  (`zhurnal.be:2117-2125`).
- **Разметка ленты ЕС** под режим БЭСМ-6 делается задачей РАЗМЕС (Э70 с
  именем `РАЗМЕС`, `khlam.be` метка `Э70`). Переписью МЛ БЭСМ-6 ↔ ЕС
  занимается программа в зоне 0506 (`rukava.be:2026`).

## 11. Реализация в симуляторе

`besm6_mg.c`, режим контроллера MG4:
- `set mg4 es` / `set mg4 noes` (только MG4, ленты должны быть сняты);
  `show mg4 type`.
- Флаг `es` хранится в `KMT` и переживает `mg_reset`.
- `mg_ctl` отдаёт `0110–0117` в `es_ctl`, `mg_event` — в `es_event`.

**Слово обмена.** `mg_io(2)` по-прежнему защёлкивает его в контроллеры 0 и 1
и ставит `armed`. Разряд 3 в `0110+u` выполняет обмен, только если слово не
использовано и его номер МЛ равен u. После обмена `armed` гаснет. Обмен
родного MG3 гасит `armed` у MG4. Так движение «зона вперёд» по приказу не
повторяет старый обмен.

**`es_ctl`.**
- Запоминает выбранный МЛ, по разр.24 гасит ГРП 35.
- По разр.13 останавливает движение (кроме перемотки).
- Иначе начинает движение и выполняет его по событию.
- Команда движущемуся МЛ игнорируется.

**`es_event`.**
- Обмен: чтение или запись, ГРП 27, через `MG_GAP_DELAY` — ГРП 35.
- Зона вперёд/назад — `sim_tape_sprecf` / `sprecr`. Пройденный МГЗ даёт
  разр.11 в `04117`.
- Группа вперёд — записи до МГЗ включительно. Группа назад — до МГЗ, лента
  встаёт перед ним (со стороны НЛ).
- МГЗ — `sim_tape_wrtmk`. Стирание следа в образе не оставляет.
- Перемотка — `sim_tape_rewind` без прерывания. Разгрузка вдобавок снимает
  ленту.

**Регистры.**
- `es_status()` (`04115`): разр.1, 5, 6, 7, 8, 9 по таблице раздела 6; НЛ не
  выставляется во время перемотки.
- `es_errors()` (`04117`): разр.11, 12, 13.
- `es_count()` (`04012`): число слов по модулю 2000.
- Без `set mg4 es` все три читаются как 0.

**Адрес в ОЗУ:**
- лист = разр.13–17 и 24–26;
- в режиме ЕС для короткой зоны к нему прибавляется абзац × 400.

**Формат образа** (SIMH `.tap`; с родными образами MG не совместим):
- **режим БЭСМ-6** — запись из 8 служебных слов (`050–057`) и 1024 слов,
  по 8 байтов с тегами, как на дисках. Разр.21 — только служебные слова;
- **режим ЕС** — запись из 400 или 2000 слов по 6 байтов, старшие вперёд,
  без тегов. При чтении словам ставится тег числа. Короткая запись даёт
  меньший счётчик, длинная — разр.12;
- МГЗ — маркер ленты SIMH.

**`attach -n`:**
- имя файла с номером 1–2047 → лента в режиме БЭСМ-6: МГЗ перед каждой из
  2010 зон, служебные слова как у родной разметки;
- имя без цифр → чистая лента для `ЕСМ`.

**Прочее:**
- `besm6_cpu.c`: `04115`, `04117`, `04012` → `es_status/errors/count`.
- `demo/dispak.ini`: `set mg4 es`.
- Тест `tests/esml.ini`, `esml.b6`: запись зоны ЕС, МГЗ и зоны БЭСМ-6,
  перемотка, чтение и проверка регистров. Перед проверкой ячейки `050`,
  записанной контроллером, тест, как и ОС, выталкивает БРЗ восемью записями:
  иначе `сч 50` берёт старое значение из буфера записи.
