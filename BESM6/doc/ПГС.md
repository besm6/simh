# ПГС: подсистема грифа секретности

Анализ исходных текстов Диспака БЭСМ-6 (`~/git/re-dispak/*.be`). Ссылки вида
`файл:строка` относятся к `re-dispak`. Обозначения `Еn` — разряд n, `Е1` —
младший, `Е48` — старший. Как ПГС рисует гриф на графопостроителе (шрифт,
кадры, образец), описано в `ГП.md` §6.3–6.5.

## Итог

- **В этой сборке ПГС вызывается из одного места:** ГП4 в конце каждого
  графика РПГ, вход 4 `ОТГП` (гриф и учётный блок на графике).
- **Кроме этого в ПГС есть вся система грифов для АЦПУ:**
  - хранение учётной записи задачи в «сейфе» на МБ;
  - печать верхней и нижней метки в рамке;
  - выдача по директиве;
  - запросы задачи на чтение учёта и смену грифа.
- **Эти пути недостижимы.** Вызовы из КЗ и ПРИК4 собираются только при
  `∧УЧЕТ` ≠ 0, а двоичный Диспак собран с `∧УЧЕТ` = 0. Для остальных
  входов вызовов нет вообще.
- **Не путать с баннером учтённых листов** в ПЕЧАТИ (`учетdw`). Тот работает
  и к ПГС не относится.

## 1. Загрузка и входы

ПГС — нерезидент.
- **Загрузка.** ГЕНС при каждом запуске переписывает его из зоны 0611 на
  программный МБ (`куспгс`, `gens.be:257,475,555`).
- **Вызов.** Через `ВЫЗНП` с дескриптором, старшие разряды которого задают
  номер входа. Таблица переходов — `pgs.be:6-17`, номер входа попадает
  в `М2`.

| Вход | Метка | Для кого | Вызов в этой сборке |
|---|---|---|---|
| 0 | `ОТБОП` | БОП, ввод задачи | вызова нет |
| 1 | `ОТПРИК` | ПРИКАЗ, директива `ВЫД` | `prik4.be:419-421`, только при `∧УЧЕТ` ≠ 0 |
| 2 | `ОТНРО` / `ОТНРОТ` | НРОТ, «работа выдай на АЦПУ (Э63 6)» | вызова нет |
| 3 | `ОТКЗ` | КЗ, конец задачи | `kz.be:371-373` «печать учета», только при `∧УЧЕТ` ≠ 0 |
| 4 | `ОТГП` | ГП4, гриф графика | да: `gp4.be:484`, `КУСПГС` = `М40В'4'М18В'3'М2В'30'` (`gp4.be:563`) |
| 5 | `ОТВРЕМ` | запрос задачи (механизм Э63) | вызова нет |

КЗ и ПРИК4, собранные с `asm.pl`, идут по ветви `∧УЧЕТ` = 0. КЗ вместо
вызова ПГС печатает посмертную выдачу через `Э64 КЗ112`; ПРИК4 пропускает
вызов. Остальные вызовы искались так:
- `Э63` в ХЛАМе (`khlam.be:1308-1345`) уходит в архив и `ДИМОН`, ПГС не
  вызывает;
- в БОП и НРОТ обращений к ПГС нет;
- других дескрипторов ПГС в `.be` нет.

## 2. «Сейф» грифов

Сейф — сектор информационного МБ (`КУСГС` = `М2В'5'`, `pgs.be:1000`).
- **Ключ** `КЛЮЧГС` лежит в слове `01777` листа.
- **Записи** — по 8 слов на канал, начиная с `01400 + 8·N` (N — номер
  канала, `ИЗАХВ`).
- **`ЧТГС`** (`pgs.be:809-832`) читает сектор малого каталога (`КУСМК`),
  берёт из него ФИО (`ЯЧФИО`, слова `768+ФИО` и `784+ФИО`), затем читает
  сейф.
- **`ЧТСЕЙФ`** (`pgs.be:949-957`): если ключа нет, `ЧИСТГС` очищает
  128 слов с `01400`, пишет ключ, и `ЗПСЕЙФ` записывает сектор обратно.
- **`ЗПГС`** (`pgs.be:843-855`) заносит запись (`ЗАГО`) в ячейку канала.

Вторая точка входа ЧАСОВ (`G50172`, см. `ЧАСЫ.md` §7) проверяет `КЛЮЧГС` в
секторе МБ и при его отсутствии очищает сектор и пишет ключ. Скорее всего,
это та же инициализация сейфа.

## 3. Что делают входы

**`ОТБОП` — ввод задачи** (`pgs.be:18-200`).
1. Переписывает учётный текст задачи (до `‾`, код 0115) по литерам.
2. Проверяет и при необходимости размножает поля грифа (`ФОГРИА`,
   `ФОГРИГ`).
3. Общий разбор `ГРПГР` (`pgs.be:426-660`) понимает:
   - гриф 1–5 (`ГРИФЫ`, `pgs.be:1051-1065`: «НЕСЕКРЕТНО», «ДЛЯ СЛУЖЕБН.
     ПОЛЬЗ.», «СЕКРЕТНО», «СОВ. СЕКРЕТНО», «ОСОБОЙ ВАЖНОСТИ»);
   - «МСЗ N»;
   - поля «ТИП», «НОМЕР», «ТЕМА», «ЗАКАЗЧИК», «ИСПОЛНИТЕЛЬ» (`ЗАГОТО`).
4. Кладёт запись в сейф.
5. Печатает на АЦПУ верхнюю метку (`ПЕЧГСН`/`ПЕЧГС`): с новой страницы
   (`Э64 0`), текст в рамке `КАНТ`/`КАНТ1`/`КАНТ2` (`pgs.be:1031-1033`, знаки
   `*`, `=`, `|`).
6. При ошибке разбора — АВОСТ 81, «ошибка учета» (`ОШУЧ`, `pgs.be:698-704`).

**`ОТПРИК`, `ОТНРОТ` — выдача по директиве `ВЫД` или запросу «выдай»**
(`ОБРЕЗ`, `pgs.be:705-737`).
1. Проверяет, что в канале есть задача (`ШИФР`).
2. На время печати маскирует её (`МШГ`).
3. Печатает метку из сейфа с новой страницы.
4. Снимает маску (`ВЫХПРИ`).

**`ОТКЗ` — конец задачи** (`pgs.be:738-750`). Печатает нижнюю метку из сейфа.
Если записи нет, печатает «*****» вместо метки (`ВЫХКЗ`).

**`ОТВРЕМ` — запрос задачи** (`pgs.be:866-995`). Параметр берётся из слова
задачи в ТУС (`ПАРАМ`).

| Запрос | Действие |
|---|---|
| «выдай» | как `ОТНРОТ` |
| «дай учет» (`ДАЙУЧ`) | 8-словная запись задачи из сейфа переписывается в память задачи; при плохом адресе — АВОСТ 58 (`ОШПАМ`) |
| «смени гриф графика» (`ГРИГРА`) | новый гриф проверяется на 1–5 (иначе `ОШУЧ`) и заносится в поле графика записи сейфа |
| иначе: смена грифа АЦПУ | нижняя метка со старым грифом (`ОТНРОТ`), новый гриф в сейф (`ГРИАЦ`/`СМЕГРИ`), верхняя метка с новым (`ПЕЧКВ`). Так гриф меняется посреди выдачи. |

**`ОТГП` — гриф графика.** См. `ГП.md` §6.4: номер машины, дата и время,
гриф, учётные поля, шифр и ФИО, признак прерванного графика. Текст
переводится в кадры графопостроителя.

## 4. Итог по достижимости

В этой сборке работает только гриф на графопостроителе. Метки АЦПУ (верхняя,
нижняя, по директиве) и запросы задачи не вызываются: соответствующие
вызовы КЗ и ПРИК4 собраны с `∧УЧЕТ` = 0, а для `ОТБОП`, `ОТНРОТ` и
`ОТВРЕМ` вызывающего кода нет.
