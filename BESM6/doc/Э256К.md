# Э256К: ПОЗУ «Электроника-256» вместо барабанов

Анализ исходных текстов Диспака БЭСМ-6 (`~/git/re-dispak/*.be`). Ссылки вида
`файл:строка` относятся к `re-dispak`. Обозначения `Еn` — разряд n, `Е1` —
младший, `Е48` — старший.

## Итог

- **`Э256К ДА`** ставит разряд 40 ТРАКТЫ (`ПРЕДЕЛ`).
- **По-видимому, раздел предназначен для полупроводниковой памяти
  «Электроника-256»**, которая стоит на месте магнитных барабанов (МБ).
- **ГЕНС обращается с такими «барабанами» как с энергозависимой памятью:**
  - при каждой генерации полностью их расписывает;
  - не считает при этом ошибки контрольного чтения;
  - вычисляет их объём по шкалам зон.
- **В этой сборке разряд 40 включает ещё и аппаратные часы в ЧАСАХ**
  (`ЧАСЫ.md`).
- **В штатном образе разряда нет.**

## 1. Описание и установка

- **РУКАВА §2.2.61** (`rukava.be:2968-2971`): «вероятно предназначалось для
  использования ПОЗУ "Электроника-256" (256К слов). В версии 117А применение
  данного параметра не требуется».
- **РУКАВА §2.2.10** (`rukava.be:2584-2585`): «ОЗУ 256К, 512К — ПОЗУ
  "Электроника-256", в одиночном или удвоенном варианте».
- **Таблица разрядов ТРАКТЫ** (`rukava.be:3059`): «40Р.: Э256К=ДА».
- **ВЫДИНС** (`vydins.be:981-984`): `Э256К нтж ДА; пе ДАЛЬШЕ; сч Е40;
  пб ВТРАКТ`.
- **Штатный образ.** ТРАКТЫ `sbor2053.bin` (вариант 10,
  `0o4004007000000400`) содержит разряды 9, 28, 29, 30, 39 и 48, разряда 40
  нет.

## 2. Где проверяется разряд 40

| Где | Что делает |
|---|---|
| ГЕНС, роспись МБ (`gens.be:1072-1085`) | Без разряда 40 сразу переход на `ррр` («РОСП. ОКОНЧ.»). С разрядом 40 ставится `прэ256` и в цикле `ровсе` по всем трактам и направлениям МБ расписывается весь «барабан». Так и надо поступать с полупроводниковой памятью, которая теряет содержимое при выключении. |
| ГЕНС, контрольное чтение после росписи (`gens.be:1418`) | `ПРБ7: сч прэ256; пе трнет`: пока стоит `прэ256`, ошибки контрольного чтения не учитываются в `ОШБ`. |
| ГЕНС2, после печати сведений о МБ `ПЕЧМБ` (`gens2.be:885-905`) | `ВОЗВВ: сч ПРЕДЕЛ; и E40; по ВОЗВ`. С разрядом 40 считаются единицы в шкалах зон МБ `ШЗНМБО` по 16 направлениям (`чед`, комментарий «ТРАКТЫ Э256К»). Результат идёт в `ТЕКМБ` и `ТЕК3+2`, то есть текущий объём «барабана» вычисляется, а не задаётся. |
| ЧАСЫ (`clock.be`, `G50075`) | `сч ПРЕДЕЛ; и E40` включает чтение аппаратных часов `4152`/`4153`. При этом ВЫДИНС для `ЧАСЫ ИПМ` ставит разряд 38 (см. `ЧАСЫ.md` §5). Либо в ЧАСАХ проверяется не тот разряд, либо часы ИПМ ставились вместе с этим оборудованием. |

Метка `нэ256` в `dmlmb.be:126-131` — только имя. Код там сравнивает `М16` с
`П3` (направление 3), разряд 40 не читает.
