# ЧАСЫ: электронные часы в Диспаке БЭСМ-6

Анализ исходных текстов Диспака БЭСМ-6 (`~/git/re-dispak/*.be`). Ссылки вида
`файл:строка` относятся к `re-dispak`, если не указано иное. Обозначения
`Еn` — разряд n, `Е1` — младший, `Е48` — старший.

## Итог

- **ЧАСЫ** (`clock.be`, нерезидент, зона 0574, загрузка с 050000) выдаёт
  задаче дату и время в одном упакованном слове.
- **Есть два источника.**
  - Аппаратные часы ИПМ: два регистра `4152`/`4153` с датой и временем в
    двоично-десятичном коде.
  - Программный счёт: время из тиков `ВРЕМЯ`, дата из слова `ГОД`.
- **Формат результата одинаков** для обоих источников (§3).
- **Аппаратный путь включается разрядом `E40` `ПРЕДЕЛ`,** хотя ВЫДИНС для
  `ЧАСЫ ИПМ` ставит разряд 38. В штатном образе нет ни того, ни другого, и
  время всегда считается программно.
- **В симуляторе** чтение `4152`/`4153` останавливает моделирование.

## 1. Вход

`НАЧАЛО` берёт код запроса из слова `'44'` блока ТУС текущей задачи
(`сч ТУС-1; уи М1; сч '44'(М1)`).
- **Код 5** — выдать время (`G50075`).
- **Код 6** — `G50061`, несколько подфункций по старшим разрядам `(М1)`.
  Одна из них вызывает другой нерезидент через `вызнп` (`D50074`).
- **Любой другой код** — `стоп`.

Все пути кончаются в `G50153`: событие в ШГ (`D50170`), прибавка к
`'41'(М1)` и выход через `БЛИСКН`. Кто ставит код запроса, не выяснено.

## 2. Аппаратные часы (`G50075`–`G50116`)

Путь выполняется только при `ПРЕДЕЛ` & `E40`.

1. `увв '4152'` даёт 20 разрядов. `увв '4153'` сдвигается влево на 20 и
   объединяется с ними в `D50171`.
2. **Разряд 21** (разряд 1 `4153`) — часы обновляются. Чтение повторяется
   сразу и без ограничения числа попыток.
3. **Разряд 22** (разряд 2 `4153`) — ошибка часов.
   - В первый раз выдаётся сообщение «2ОШ ЭЛ ЧАСОВ» через `ТВ40`.
   - Затем ожидание одного тика (`сч E1; пв ТАЙМЕР`) и повтор, всего до 8
     чтений (`М14` от −7).
   - После этого — переход на программный путь.
4. **Исправное значение перепаковывается.** `сбр в'0017774003777777'`
   собирает разряды 1–20 и 30–40, `рзб` раскладывает их по байтам
   результата (§3). `сбр` собирает к старшему концу слова, обе команды
   сохраняют порядок разрядов.

Регистры:

| Регистр | Разряды | Содержимое |
|---|---|---|
| `4152` | 1–7 | секунды, BCD 00–59 |
| `4152` | 8–14 | минуты, BCD |
| `4152` | 15–20 | часы, BCD 00–23 |
| `4153` | 1 | идёт обновление |
| `4153` | 2 | ошибка часов |
| `4153` | 10–15 | число, BCD 01–31 |
| `4153` | 16–20 | месяц, BCD 01–12 |

Ширина полей (7, 7, 6, 6, 5 разрядов) точно совпадает с тем, что нужно для
BCD. Прерываний нет, установить часы программно нельзя.

## 3. Формат результата

Результат записывается в слово задачи `(М1)` (`G50120`).

| Разряды | Поле |
|---|---|
| 9–15 | секунды (BCD) |
| 17–23 | минуты (BCD) |
| 25–30 | часы (BCD) |
| 33–38 | число (BCD) |
| 41–45 | месяц (BCD) |

Если в `D50031` (номер работы, полученный по `нед`) стоит разряд 6, в
`5(М1)` дополнительно пишется `в'0000000201300007'`.

## 4. Программный путь (`G50124`)

1. `ВРЕМЯ` — тики по 50 в секунду. Время делится последовательным вычитанием
   констант `ЧАС` (180000 — час, 3000 — минута, 50 — секунда).
2. Каждое частное переводится `ПЕРЕВ` (`disp70.be:2165`) в десятичные цифры
   по байту на цифру. Две младшие цифры каждого числа собираются в
   `D50163`.
3. `сбр ПРОБ6` (шесть пробелов, то есть маска 017 в каждом байте) сжимает
   цифры в 24-разрядное BCD `ччммсс`. Сдвиг вправо на 16 ставит его в
   разряды 9–32 — туда же, куда попадает значение аппаратных часов.
4. Число и месяц берутся из слова `ГОД` ДИСП70:
   - разряды 30–35 `ГОД` идут в разряды 33–38 результата
     (`сда 64-13; рзб в'0003740000000000'`);
   - разряды 25–29 идут в разряды 41–45 (`сда 64-19; рзб в'0760000000000000'`).

## 5. Конфигурация

- **РУКАВА §2.2.13** (`rukava.be:2607-2617`): `ЧАСЫ ЗАВОД` — время задаёт
  оператор по своим часам; `ЧАСЫ ИПМ` — «вариант часов, сделанных в ИПМ АН
  СССР». Без раздела принимается заводской вариант.
- **Таблица разрядов РУКАВЫ** (`rukava.be:3040-3060`): «38Р.: ЧАСЫ=ИПМ»,
  «40Р.: Э256К=ДА».
- **ВЫДИНС** (`vydins.be:1498-1512`, `зпчасы`: `сда 64-37`) для `ЧАСЫ ИПМ`
  ставит разряд 38 ТРАКТЫ.
- **ЧАСЫ проверяет `E40`.** В этом двоичном коде `ЧАСЫ ИПМ` аппаратный путь
  не включает, а `Э256К ДА` включил бы.
- **Штатный образ.** ТРАКТЫ `sbor2053.bin` (вариант 10,
  `0o4004007000000400`) содержит разряды 9, 28, 29, 30, 39 и 48. Ни 38, ни
  40 нет, поэтому время всегда считается программно.

## 6. В симуляторе

`04152`/`04153` попадают в нереализованный диапазон `04140–04157` в
`cmd_033` (`BESM6/besm6_cpu.c`, «считывание строки перфокарты») и
останавливают моделирование с `STOP_UNIMPLEMENTED`. Чтобы поддержать часы
ИПМ, нужно:
1. отдавать в `4152`/`4153` дату и время хоста в BCD по таблице §2, с
   разрядами 1 и 2 `4153` равными 0;
2. ставить в ТРАКТЫ разряд 40 (с учётом расхождения из §5).

## 7. Вторая точка входа

Код с `G50172` (`употр ЧАСЫ(М1)`) к часам не относится:
1. читает зону (`ФИЗОБМ`, `D50241`/`D50240`);
2. проверяет ключ `КЛЮЧГС` в слове 0377;
3. если ключа нет, очищает зону и записывает ключ;
4. затем переписывает два слова (`D50244`, `D50245`).

Назначение не выяснено.
