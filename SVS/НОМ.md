# Директива НОМ: каталог ввода и очереди вывода

Разбор по исходным текстам Диспака СВС (`besm6.github.io/sources/dispak-svs/`,
ниже без каталога). На симуляторе директивы не проверялись.

Директива НОМ показывает две вещи:

* **каталог ввода** — введённые задачи (`НОМ <шифр>`, `НОМ <число>`);
* **спул вывода** — одна зона на диске, в ней по очереди на каждый тип
  устройства вывода: АЦПУ, ПИ (перфоратор карт), ПЛ (перфоратор ленты)
  (`НОМВ`, `НОМИ`, `НОМЛ`, `НОМО`).

## 1. Разбор директивы (НЕРОТ)

НОМ — директива 22 (`КОНК П'НОМ'`, `нерот.bemsh:1264`). Подпрограмма `НОМ`
(`нерот.bemsh:807-833`) выбирает до четырёх цифр (`ВЫБЧИ`) и смотрит
следующий символ:

* буква В, И, Л или О (маска `ТВИЛО КОНД Х'2092'`, `нерот.bemsh:1451`) —
  запрос по спулу: `ТР4 := Е48 | <разряды буквы>` (метка `НОМВ`, «ПРИЗН.НОМВ»);
* иначе (`НОМШ`) задан шифр («ВЫДАТЬ НОМЕР В КАТАЛОГЕ», уход на `ПР21А`)
  или только число: `ТР5 := 0`, в `ТР4` — число.

Исполняет директиву `прик7.bemsh` (`ПРИК7`, директива N22).

## 2. Каталог ввода: `НОМ <шифр>` / `НОМ <число>`

`прик7.bemsh:13-102`.

* Читается зона каталога `КУС545` (`дисп80.bemsh:836`), «КАТАЛОГ ШИФРОВ И
  ЗОН ВВОДА» на диске ввода, просматривается 256 записей.
* `НОМ <шифр>` (`ТР5 = <шифр>`): ищет задачу и печатает `<шифр> <N СКВ>`.
  N СКВ — позиция задачи в каталоге; по-видимому, это номер, который
  принимает директива `СКВ`.
* `НОМ <число>` (`ТР5 = 0; ТР4 = <число>`): печатает 9 записей подряд,
  начиная с позиции 8·N (`ТР4 И П37`, `СДА 64-3`), — каталог листается
  порциями.
* Ничего не найдено — `НЕТ` (`ТНЕТ`).

## 3. Спул вывода: `НОМВ` / `НОМИ` / `НОМЛ` / `НОМО`

`прик7.bemsh:176-460`; вход `НОМВХХ`, когда в `ТР4` стоит `Е48`.

### 3.1. Что показывает каждая буква

| Директива | ТР4 | Выдача |
|---|---|---|
| `НОМВ` | `Е48` | АЦПУ: строки состояния `ИНФА`, затем очередь на АЦПУ |
| `НОМИ` | `Е48+Е47` | ПИ: строки состояния `ИНФИ`, затем очередь на ПИ |
| `НОМЛ` | `Е48+Е46` | ПЛ: строки состояния `ИНФИ`, затем очередь на ПЛ |
| `НОМО` | `Е48+Е45` | всё: `ИНФА`, `ИНФИ`, `ИНФЧПК`, затем все три очереди |

### 3.2. Строки состояния

* `ИНФА` (АЦПУ):
  * `НЕТ:` — выключенные АЦПУ, по `МГРП` (`Е1`/`Е3` для А0/А1). То есть
    в МГРП, кроме номера смены, лежат и признаки доступности устройств.
  * `СБОЙ:` — АЦПУ в сбое, по `ШИФРАЦ` (`Е25`/`Е27`).
* `ИНФИ` (перфораторы):
  * `N У-В: ПИ<n> ПЛ<n>` — номера работающих ПИ и ПЛ, по `НУСВУ`
    (`Е28`/`Е27`);
  * `НЕТ:` и `СБОЙ:` — так же, по `МГРП` `Е2`/`Е4` и `ШИФРАЦ` `Е26`/`Е28`.
* `ИНФЧПК` (только в `НОМО`): `ВВОД: В0/В1/ФС0/ФС1` — выбранное устройство
  ввода, по `НУСВУ И П3`, или `ЗАПР.` при запрете ввода (`НУСВУ И ЕЗАПРВ`).

Перечень `НЕТ:`/`СБОЙ:` строит общая подпрограмма `ПЕРЕЧ` по шаблону
разрядов `ШАБЛО`.

### 3.3. Зона спула

`НОМВЫВ` читает зону `КУСВЫВ` («КУС ЗОНЫ ВЫВОДА», `дисп80.bemsh:839`, поле
зоны 0450) с диска ввода-вывода `НОММЛ1` в буфер (адрес в М2). Ту же
разметку использует спулер вывода РОБОТ (`робот.bemsh:1761-1762`; там же
`КУСКТ КОНД М24В'450'`), а также `прик6.bemsh:475` и `прик10.bemsh:121`.

Адреса слов — относительно начала зоны:

* **`ОЧКЛ` (слово 01664):** 8 слов, по одному на класс (в коде «ЦИКЛ ПО 8
  КЛАССАМ»). В каждом слове — головы очередей для каждого типа устройства:
  АЦПУ, ПИ, ПЛ. Поле выбирается таблицами маски и сдвига `Е48П37-1(М4)` /
  `КСД1-1(М4)` при М4 = 1 (АЦПУ), 2 (ПИ), 4 (ПЛ). Ноль — в классе нет
  выдач на это устройство (`НОМВ1`).
* **`ШОЧ` (слово 01675):** элементы очередей, по слову на задачу:

  | Разряды | Содержимое |
  |---|---|
  | 48-25 | шифр |
  | 24-15 | первая зона выдачи задачи (`СДА 64+14 / И П1777`) |
  | 14 | выдача идёт сейчас (без него задача стоит в очереди) |
  | 13-8 | назначенные ЭВМ и номер устройства (`Е13П8`) |
  | 7-1 | ссылка на следующий элемент очереди (`П177`) |

* **Цепочка зон:** по слову на зону спула. Разр.10-1 — следующая зона
  (`П1777`), `Е44Е43` — добавка 0-3 зоны; директива проходит по цепочке и
  считает зоны.
* **`СВ` (слово 01646):** по два слова на ЭВМ (А0 и А1) — зона, которую АЦПУ
  выдаёт сейчас (`СВ-2(М2)` при М5 = N ЭВМ · 2). По ним считается остаток
  зон у выдаваемой задачи.

### 3.4. Формат строки

Пример из `журнал.bemsh:888-901` («ИЗМЕНЕНА ДИРЕКТИВА "НОМВ" - ВЫДАЧА
ОЧЕРЕДИ НА ПЕЧАТЬ»):

```
419918 10 001
101200 20 002 А0
555555 07 010/003 А1+
```

Столбцы:

1. шифр задачи;
2. системный идентификатор задачи — позиция элемента в очереди (`ТNИДЕН`,
   из относительного адреса элемента);
3. число зон для выдачи; у задачи, которая уже выдаётся, через `/` — число
   оставшихся зон;
4. устройство, на которое распределён шифр или идёт выдача (`А<n>`, `ПИ`,
   `ПЛ`, при необходимости `Э<n>` — номер ЭВМ); `+` — выдача этой задачи
   печатается в данный момент.

## 4. Не выяснено

* Что означают 8 классов очереди и как задачи распределяются по ним — это
  решают РОБОТ и код вывода, они не разбирались.
* Разметка зоны спула выведена только из кода директивы; с данными живой
  системы (дамп зоны `КУСВЫВ`) не сверялась.
